# omen-control

One control panel for the lighting and CPU-cooler LCD of an HP OMEN 45L desktop on Linux.

**Status: design stage. Nothing here works yet.**

- Front fans and case lights (HP "TracerLED", USB `103c:84fd`) and RAM RGB: driven through [OpenRGB](https://openrgb.org).
- CPU cooler LCD (HP "LCD-PUMP", USB `03f0:7397`): custom 480x480 images, sent by a small background service.

This is an unofficial hobby project, not affiliated with HP.
